OFFLINE WORKFLOW GUIDE

3-Minute Canvas Guide

1Pan and Zoom

Drag the canvas to move; use the wheel to zoom around the pointer. Press 0 to fit the full workflow.

2Edit and Connect

Drag a node header to reposition it. Press C, then select output and input ports to create a connection.

3Assets and Templates

Add local assets or character references from the libraries, or insert an editable sub-workflow from the toolbox.

4Node Inspector

Select a node to edit its title, description, prompt, model, aspect ratio, and connections.

5History and Saving

Every operation is saved locally. Undo, redo, and JSON import/export are all supported.

6Case Study Tour

Choose a stage or start Auto Tour to follow Brief → Assets → Direction → Generation → Finish → Delivery.
